NGajiPlus FINAL - GitHub Pages
================================
CARA UPLOAD:
1. Buat repository GitHub, misalnya website-ngajiplus.
2. Upload SELURUH isi folder ini (index.html harus berada di root repository).
3. Buka Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save.
7. Tunggu proses build selesai, lalu buka alamat GitHub Pages Anda.

EDIT MATERI:
- Semua data demo ada di data.js.
- Ganti URL YouTube pada video.url.
- Masukkan MP3 Anda ke folder audio/ dan ubah audio.url.
- Masukkan PDF Anda ke folder pdf/ dan ubah pdf.url.
- Ganti gambar pada assets/img/.

CATATAN:
Versi ini adalah versi statis yang siap GitHub Pages. Supabase dapat ditambahkan pada tahap berikutnya untuk dashboard admin dan database.
